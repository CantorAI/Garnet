# Dataset.1980Love

Phase 2 VLM reference-test fixture.

The dataset contains sampled frames from the 2015 film
*Love in the 1980s*, directed by Huo Jianqi, with adjacent
detector metadata JSON files.

The film frames are included only as small visual-language-model test fixtures.
Copyright in the underlying film and imagery remains with its respective
rightsholders; their inclusion does not place them under the Garnet source-code
license or imply endorsement by the rightsholders.

Phase 2 tests use the first JPG/JSON pair as a small, stable image prompt fixture for:

- Hugging Face Qwen-VL reference inference.
- Garnet Qwen-VL parity scaffolding once Garnet runtime support is ready.
